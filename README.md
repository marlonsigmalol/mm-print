# MM Print

Printing, paper templates and original practice assessments for Mac.

[Visit the project page](https://marlonsigmalol.github.io/mm-print/) · [Download the latest release](https://github.com/marlonsigmalol/mm-print/releases/latest) · [Report an issue](https://github.com/marlonsigmalol/mm-print/issues)

Universal for Intel and Apple silicon. Requires macOS 13 or later.

MM Print is currently in closed beta. The app includes manual duplex printing, PDF/Word workflows, assessment building and Nemotron integration. AI-generated assessments need human review before use. Provider availability and limits are determined by the provider.

This repository contains the project page, release notes and downloads only. Application source code is not published here. No licence to redistribute the application or its branding is granted by this repository.

Mac releases currently use Apple Development signing and are not notarized. macOS may display a security warning on first installation. Managed Macs may require administrator approval. Updates are downloaded only when requested, and installation waits until you choose to restart. An active assessment or print session blocks the update restart.

Your exam records, provider keys and preferences remain stored locally. Update checks contact GitHub to retrieve public release information; they do not upload assessment content or provider keys.
