MM Print is in closed beta. Releases currently use Apple Development signing and are not notarized, so first-time installation may show a macOS security warning. Managed Macs may require administrator approval.

Once an updater-enabled version is installed, MM Print can check quietly for new releases. You choose when to download and restart. Assessment content and provider keys are not sent with update checks.
